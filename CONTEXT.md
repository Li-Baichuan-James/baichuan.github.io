# Personal Academic Homepage

This context defines the language used for the personal academic homepage and keeps the public profile consistent while the site moves to a static single-page presentation.

## Profile Language

**Homepage content**:
Personal material already shown on the current homepage, plus clearly identified additions from the latest resume. It does not include the Academic Pages demonstration content.

**Resume fact**:
A claim supported by the latest supplied resume. When the homepage and resume describe the same fact differently, the resume fact is canonical.

**Hidden social entry**:
A social destination whose asset or placeholder is retained in the repository but whose icon and link are not currently rendered publicly.

**Static homepage**:
The public root page served directly from `index.html`, with no Jekyll rendering required for the visitor-facing experience.
